# System Informer 简体中文社区汉化增强补丁

由 **Enshen1121** 维护的非官方预览项目，在独立的 `ZH` 副本中提供简体中文界面和“第三方”管理页。原项目为 [winsiderss/systeminformer](https://github.com/winsiderss/systeminformer)，本项目不代表原作者，也未获得其官方背书。

**首版：v0.1.0-preview · Windows 10/11 x64 · 仅适配 System Informer 4.0.26241.138。**

## 下载与安装

1. 从本仓库 [Releases](https://github.com/Enshen1121/systeminformer-zh-cn/releases) 下载 `SystemInformer-ZH-v0.1.0-preview-win-x64-addon.zip`，解压到可写目录。
2. 自行从[原项目发布页](https://github.com/winsiderss/systeminformer/releases)获取 **4.0.26241.138 的官方便携文件**，保持原目录结构完整。安装脚本以文件版本及 SHA256 双重核对，其他版本或缺少文件会拒绝安装。
3. 在补丁解压目录打开 Windows PowerShell 5.1 或 PowerShell 7，执行以下命令，把示例路径改成官方程序所在目录：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Zh.ps1 -OriginalDirectory "D:\Apps\SystemInformer"
   ```

   `Bypass` 仅用于这一次脚本进程，不修改系统执行策略。脚本源码可在运行前查看；无需 Resource Hacker、编译器或第三方安装器。
4. 脚本在官方目录内新建 `ZH`，仅修改该副本；随后运行 `ZH\Start-ZH.cmd`。如果已有 `ZH`，安装会拒绝覆盖，请换用一份干净的官方文件副本。

补丁包不含上游 EXE、驱动、个人设置或进程名单。它含本项目插件、中文资源、安装器和源码；不是可独立启动的完整程序包。失败目录会留下 `INSTALL-FAILED.txt`，不得把它当作安装完成；成功标记为 `installation.json` 中的 `Ready: true`。

## 汉化与新增内容

| 内容 | 本版实现 |
| --- | --- |
| 对话框资源 | 16 个模块、2,102 处标题/控件文本替换，保留对话框布局和程序代码 |
| 动态界面 | 3,646 项非原文词典，覆盖菜单、主页标签、工具栏、常见表头、状态栏、设置等固定文本 |
| 新主页标签 | 在“设备”后并排增加“第三方” |
| 第三方名单 | 按程序完整路径归并，显示名称、描述、公司、运行数量/PID、自启状态、分类、保护原因和路径 |
| 扫描操作 | 刷新、管理员扫描、全选可操作项、清空选择、查看 CSV 名单 |
| 一键关闭 | 仅对勾选且未保护的程序尝试结束进程，并处理属于该程序的运行服务 |
| 一键关闭自启 | 禁用识别到的 Run/RunOnce、启动目录快捷方式、直接执行程序的计划任务和 Win32 服务启动项 |
| 一键禁用 | 组合执行“关闭”和“关闭自启”；不等于禁止以后手动启动或卸载程序 |
| 恢复记录 | 修改前保存本地恢复记录；提供恢复脚本，并核对用户和启动项身份 |

“第三方”按路径、公司、系统组件和保护规则判断，不仅依据“描述”一栏。描述可能为空或不准确；可选 Microsoft 应用也可能出现在名单内。系统核心组件、管理工具以及识别到的安全/硬件组件受到保护，不会被“全选可操作项”勾选。保护规则无法证明任意其他程序都可安全关闭。

所有写操作均需勾选并确认。首次打开只扫描，不会自动批量禁用。普通扫描可能因权限无法读取部分路径；管理员扫描会触发 Windows 提权。程序身份、任务动作、快捷方式和服务归属在修改前重新校验；发生变化或权限不足时跳过并记录结果。

## 恢复与卸载

CSV 名单保存在本机 `ZH\outputs\third-party`，扫描中间文件在 `ZH\work\third-party`，恢复记录在其 `history` 子目录。请先查看具体备份中的 `changes.json`、`snapshot.json` 及操作结果，再按以下命令指定实际变更记录文件恢复：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\Apps\SystemInformer\ZH\third-party\restore.ps1" -Changes "D:\Apps\SystemInformer\ZH\work\third-party\history\实际备份子目录\changes.json"
```

管理员范围的变更需在相应权限下恢复；用户 SID 或启动项内容变化时可能拒绝恢复。恢复启动项不恢复已结束进程的未保存内容。仅删除 `ZH` 不会撤销已经应用的系统启动项修改，应先恢复所需项目、保存备份，再退出并删除副本。

## 支持范围与已知限制

- 本版以 Windows x64 为发布目标；附带 x86 插件用于对应辅助组件，不宣称已支持独立 32 位系统。ARM64、Linux、macOS 不在此版范围。
- 部分动态英文、格式化文本和第三方扩展界面仍可能未翻译。词典逐项匹配，不承诺 100% 中文覆盖。
- 自动启动识别不能覆盖商店 StartupTask、间接脚本/命令链、组策略、软件自恢复机制等所有方式。“未识别入口”不等于绝不会再启动。
- 默认禁用自动更新插件，以免覆盖补丁或造成版本不匹配。升级上游版本需重新适配，不应绕过哈希校验。
- 使用 `-nokph` 启动，不安装内核驱动、不修改驱动签名或 Windows 安全设置。需要内核驱动的高级功能受限。
- 汉化后的宿主和资源模块已改变，原有数字签名不再有效；自建插件未使用商业证书签名，不得宣称是官方签名版本。
- 已完成 x64 界面验证及本地逻辑测试；完整的管理员服务禁用/恢复回归、真实 x86 宿主、重启/登录与长期稳定性尚未全部验证。详见[验证记录](./docs/VALIDATION.md)。
