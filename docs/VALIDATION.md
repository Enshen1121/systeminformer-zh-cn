# 验证范围

本项目为预览版，按以下范围理解验证结果，不将逻辑测试等同于所有真实系统操作验证。

## 已有功能验证

- Windows PowerShell 5.1 和 PowerShell 7 后台逻辑测试各 30 项，包括路径边界、进程身份、混合动作计划任务、快捷方式被替换、服务归属和恢复记录校验。
- x64/x86 原生第三方页面测试各 13 项，包括列、Unicode 名单解析、受保护项目勾选限制和请求生成。
- Windows x64 实际宿主界面已确认中文及新增主页标签可用。

## 未完成的真实环境验证

完整管理员服务禁用/恢复及修正后的完整提权回归尚未完成；真实独立 x86 宿主、重启/登录行为及长期运行未完成。不可据此宣传所有自动启动方式均可关闭、所有变更均可恢复或覆盖所有设备。

## 发布安装器

发布前安装器通过 39 项检查，覆盖原文件及补丁哈希、先检查后创建、已有 ZH 拒绝覆盖、目录联接/路径越界拒绝、失败目录不留成功标记、清洁配置和无驱动副本。资源测试解析全部 16 份资源，共 410 个对话框（含 2 个文字命名资源），并核对截断和异常头部拒绝行为；安装后全部资源回读一致。

另外确认 16 个修改模块的 128 个非资源 PE 节逐字节保持原样，原目录 47 个基线文件 SHA256 全部不变。新生成的 x64 副本可启动，两项自建插件加载，动态汉化状态为 active；测试仅退出该次启动的测试副本。x64/x86 插件均从公开源码以 `/W4 /WX` 重新构建通过。

测试目录、个人配置及扫描产物不进入公开仓库。上述结果不包含完整管理员写操作回归，不构成所有设备或长期稳定性的保证。
